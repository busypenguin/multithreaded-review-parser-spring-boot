Парсер отзывов

Запустите сбор и дождитесь результата. Локальный пример содержит три отзыва на трёх страницах и работает без внешнего сайта.

Готов к запуску

АвторОтзывРейтингДата

Проверка через HTTP

POST http://localhost:8080/parse
Content-Type: application/json

{"url":"http://localhost:8080/demo/product?page=1"}

GET http://localhost:8080/jobs/идентификаторИзОтвета
GET http://localhost:8080/answer?sort=rating&direction=desc

Статус RUNNING означает сбор, DONE означает завершение, FAILED содержит описание ошибки. Каждую минуту выполняется повторный сбор успешно обработанных ссылок. Повторные отзывы не добавляются в базу.

Внешние страницы поддерживаются при наличии отзывов Schema.org JSON LD с текстом, автором, рейтингом от одного до пяти и датой. Также добавлен разбор HTML карточек Отзовика. Страницы, требующие JavaScript, авторизации или прохождения капчи, не поддерживаются. Полный текст доступен только тогда, когда он присутствует в полученном HTML. Разбираются первая страница и до девяти ссылок пагинации с неё.
