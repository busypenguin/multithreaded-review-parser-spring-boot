Парсер отзывов.

Запуск.

Установить IntelliJ IDEA Community или Giga IDE и JDK версии 17 или новее.
Открыть папку проекта в выбранной среде разработки.
Дождаться загрузки Maven зависимостей. Для первой загрузки нужен интернет.
Выбрать установленный JDK в настройках проекта.
Открыть класс ReviewsApplication и нажать зеленую кнопку запуска рядом с методом main.
Дождаться сообщения Started ReviewsApplication в консоли.
В браузере открыть localhost на порту 8080.
Нажать кнопку Собрать отзывы и дождаться статуса DONE.
В таблице появятся три демонстрационных отзыва.
Выбрать сортировку и нажать Получить результаты.
Повторный сбор не создает копии отзывов.
Таблица показывает отзывы только по ссылке в поле ввода.
Для проверки русскоязычного магазина скопировать ссылку Литрес из файла requests.http в поле ввода.
Это отзывы реальных читателей о книге Джорджа Оруэлла 1984. При живой проверке сохранены четыре отзыва.
Собираются доступные в HTML отзывы с оценкой автора. Комментарии без оценки пропускаются.
Для проверки интернет магазина скопировать ссылку Sweetwater из файла requests.http в поле ввода.
Это страница реального микрофона Shure SM58. При живой проверке сохранены пять отзывов.
Собираются отзывы, опубликованные магазином в разметке Schema.org JSON LD.
Это может быть только часть отзывов, видимых в браузере.
При запуске автоматически используются системные настройки прокси Windows.
Для остановки нажать красную кнопку остановки в среде разработки.

Отзовик, otzovik.com.
Передать ссылку на страницу отзывов товара. Реализован разбор карточек и загрузка полных текстов отзывов.
Разбор проверен на сохраненном HTML реальной страницы. Прямой сбор при проверке был заблокирован капчей.
Использование возможно, когда сайт отдает страницу без капчи. Обход капчи не реализован, доступность не гарантируется.

Полные ссылки и примеры JSON запросов для этих сайтов находятся в файле requests.http.

Проверка запросами.

Полные адреса и JSON запросов приведены на главной странице приложения и в файле requests.http.
Отправить POST запрос на parse с полем url.
Получить идентификатор задания из ответа.
Выполнять GET запрос на jobs с идентификатором до статуса DONE или FAILED.
Выполнить GET запрос на answer для получения сохраненных отзывов.
Параметр sort принимает rating, author, date.
Параметр direction принимает asc, desc.
Необязательный параметр source выбирает отзывы по исходной ссылке.
Некорректные параметры возвращают код 400. Неизвестное задание возвращает код 404.
При восьми одновременно выполняемых заданиях следующий запрос возвращает код 429.

Как работает проект.

Контроллер принимает запрос. Сервис запускает сбор. Репозиторий сохраняет результат в H2.
RestTemplate получает HTML страницы. Jsoup и Jackson извлекают отзывы.
Кастомный ExecutorService использует четыре потока и ограниченную очередь.
Страницы пагинации загружаются параллельно. Потоки не ожидают другие задания пула.
ConcurrentHashMap хранит задания. AtomicInteger считает обработанные отзывы и активные задания.
Результаты извлекаются из H2 и фильтруются и сортируются через parallelStream.
Scheduled каждую минуту повторяет сбор успешно обработанных ссылок.
Пока задание по ссылке выполняется, планировщик не запускает повторное.
База хранится в папке data и сохраняется после перезапуска.
История заданий хранится в памяти и очищается после перезапуска.
После перезапуска нужно снова передать ссылки для сбора по расписанию.

Ограничения.

Демонстрационные страницы содержат учебные данные и работают без внешнего интернета.
Внешние страницы поддерживаются при наличии отзывов в разметке Schema.org JSON LD или HTML карточек Отзовика.
Также поддерживается IRecommend. С карточки товара загружается до девяти полных отзывов.
Поддерживается страница отзывов книги в Литрес. Оценка определяется по выбранным звездам автора отзыва.
Пример реальной карточки IRecommend приведен в файле requests.http.
При проверке с IRecommend удалось собрать реальные отзывы без капчи.
Нужны текст, имя автора, дата и рейтинг от одного до пяти.
Для Отзовика дополнительно загружаются страницы полных отзывов.
Если полный отзыв недоступен, сохраняется текст карточки.
При проверке живой страницы Отзовик потребовал капчу. Такой сбор получает статус FAILED.
Собирается первая страница и до девяти ссылок пагинации с первой страницы.
Сортировка даты использует строку. Для правильного порядка внешние даты должны иметь формат ISO.
Страницы с обязательным JavaScript, авторизацией и капчей не поддерживаются.
Поддержка произвольных страниц Ozon и AliExpress не гарантируется.
Ошибка загрузки или отсутствие подходящих отзывов отражается в статусе FAILED.
При ошибке одной страницы уже собранные отзывы остаются в базе.
Счетчик задания показывает обработанные отзывы, а не число новых записей.
Приложение предназначено для локальной учебной проверки.

Тесты.

Открыть папку тестов в среде разработки и запустить класс ReviewApplicationTest.
Тесты проверяют полный сбор с трех страниц, отсутствие повторов, сортировку и ошибки запросов.
Отдельный тест проверяет актуальную разметку карточек и пагинации Отзовика.
